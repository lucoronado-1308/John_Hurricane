# Oceanographic Variability and Air-Sea CO2 Flux Analysis

This repository contains Python workflows and processing examples developed for the analysis of environmental variability and air-sea CO2 fluxes in the Mexican Pacific.

The analyses include:
- sea surface temperature (SST),
- chlorophyll-a (Chl),
- sea surface salinity (SSS),
- pCO2 variability,
- air-sea CO2 flux calculations.

The repository integrates observational and modeled datasets to explore environmental changes associated with regional oceanographic variability.

Included workflows demonstrate:
- NetCDF and CSV processing,
- temporal analysis,
- spatial visualization,
- environmental anomaly assessment,
- comparison between observational and modeled products.

## Data types

- NetCDF files
- CSV datasets
- Environmental time series
- Gridded oceanographic products

## Main tools

- Python
- xarray
- numpy
- pandas
- matplotlib
